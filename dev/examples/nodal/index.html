Probit regression

This example replicates Section 4.1 of Chib (1995): variable selection in a binary probit regression for the nodal involvement data. It is the simplest setting with latent data: one parameter block $\beta$ and the latent utilities $z$ of Albert and Chib (1993).

using MargLikeGibbsOutput, Distributions, LinearAlgebra, Random

Data

The data are from 53 patients with prostate cancer (Table 1 of the paper). The response $y$ is whether the cancer has spread to the lymph nodes, and the columns are $y$, age ($x_1$), level of serum acid phosphate ($x_2$), X-ray result ($x_3$), tumor size ($x_4$) and tumor grade ($x_5$).

Model

The model is $\Pr(y_i = 1) = \Phi(x_i'\beta)$ with prior $\beta \sim N(a, A^{-1})$. With latent utilities $z_i \sim N(x_i'\beta, 1)$ and $y_i = I(z_i > 0)$, the Gibbs sampler has the full conditionals

\[\beta \mid y, z \sim N\big(B(Aa + X'z), B\big), \qquad B = (A + X'X)^{-1},\]

and $z_i \mid y, \beta \sim N(x_i'\beta, 1)$ truncated to $(0, \infty)$ if $y_i = 1$ and to $(-\infty, 0)$ otherwise. Each full conditional is a function of the current state, the data and the prior hyperparameters that returns a distribution.

function β_conditional(state, data, prior)
    B = inv(Symmetric(prior.A + data.X'data.X))
    return MvNormal(B * (prior.A * prior.a + data.X'state.z), B)
end

function z_conditional(state, data, prior)
    μ = data.X * state.β
    return product_distribution([y ? truncated(Normal(m), 0, Inf) : truncated(Normal(m), -Inf, 0)
                                 for (y, m) in zip(data.y, μ)])
end

The log-likelihood has the latent utilities integrated out, and there is a single parameter block, so the posterior ordinate is $\pi(\beta^* \mid y) = \int \pi(\beta^* \mid y, z)\, \pi(z \mid y)\, dz$, estimated by averaging the full conditional density of $\beta$ over the draws of $z$.

probit = GibbsModel(
    conditionals = (β = β_conditional,),
    latents = (z = z_conditional,),
    loglik = (θ, data) -> sum(logcdf(Normal(), (2y - 1) * η) for (y, η) in zip(data.y, data.X * θ.β)),
    logprior = (θ, prior) -> logpdf(MvNormalCanon(prior.A * prior.a, prior.A), θ.β),
)

Marginal likelihoods

Chib compares nine models that differ in the covariates. As in the paper, each prior mean is 0.75 and each prior standard deviation 5, and the estimates use 5000 draws after a burn-in of 500. The numbers to the right are the log marginal likelihoods in Table 2.

models = [(:C,) => -38.503, (:C, :x1) => -43.175, (:C, :logx2) => -37.916,
    (:C, :x3) => -35.323, (:C, :x4) => -37.234, (:C, :x5) => -39.075,
    (:C, :logx2, :x4) => -36.140, (:C, :logx2, :x3, :x4) => -34.553,
    (:C, :logx2, :x3, :x4, :x5) => -36.233]

rng = Xoshiro(1995)
results = map(models) do (terms, chib1995)
    X = hcat(covariates[terms]...)
    k = size(X, 2)
    prior = (a = fill(0.75, k), A = Matrix(I(k) / 5^2))
    estimate = chib(rng, probit, (; y, X), prior, (β = zeros(k),); ndraws = 5_000, burnin = 500)
    println(rpad(join(terms, " + "), 28), estimate, "   Chib (1995): ", chib1995)
    estimate => chib1995
end
